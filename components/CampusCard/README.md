# CampusCard

Card grande de foto em pares (`gm-col-6`) dentro da seção verde (`gm-green`): título `card-title-xl` 51px bold em duas linhas, botão-ícone branco 48px à direita, degradê `green-forest` na base.

Hover: o botão vira `lime` com seta `green-forest`.

`gm-green` é a seção cheia em `green-forest` com cantos inferiores `radius-md`, eyebrow em `lime` e título branco 40px. Use no máximo uma seção verde por página.
