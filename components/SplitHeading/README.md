# SplitHeading

Cabeçalho de seção em duas metades separadas por um filete vertical de 1px (`line`): à esquerda eyebrow soft + título curto 34px; à direita a frase de efeito 45px alinhada à direita com o final em `green-vivid` bold.

Use para abrir seções com grade de cards logo abaixo. No mobile empilha e alinha à esquerda.

Para títulos simples use `gm-h2` (40px/1.3, 500) com o trecho de destaque em `<span class="gm-hl">`.
