# Header

Barra branca de 84px com a logo oficial à esquerda (42px de altura), menu central em `nav` (15px 500, `text`, seta de dropdown) e o botão primário à direita com `radius-lg` (25px).

Fica fixa no topo com `border-bottom` cinza claro. Abaixo de 1024px o menu vira drawer (sombra `shadow-lg`). Use sempre a logo do grupo Logos, nunca recriada em texto.
