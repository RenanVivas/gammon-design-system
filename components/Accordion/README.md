# Accordion

Lista numerada de diferenciais: itens `accordion` 24px regular com número `01.` e filete `line` de 1px embaixo. Um item aberto por vez; o painel abre com `grid-template-rows` em `dur-move` e mostra texto `text-muted` + foto `radius-sm` + botão escuro.

Fica à direita (7 colunas) de um bloco de título com eyebrow soft, `gm-h2` com destaque verde e parágrafo, que acompanha a rolagem (sticky) no desktop.

Precisa do script curto de abrir/fechar (está no preview) e de `aria-expanded` nos botões. Numeração só quando a lista é de fato uma sequência de motivos.
