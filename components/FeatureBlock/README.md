# FeatureBlock

Bloco cinza (`surface-200`, `radius-md`, padding 30px) em duas colunas: imagem `radius-sm` à esquerda e texto à direita (eyebrow, `h4` 35px, parágrafo 15px, botão claro).

Para conteúdo institucional que pede uma ação só (Capelania, Pastoral, Bolsa). Inverta a ordem em blocos consecutivos. No mobile empilha.
