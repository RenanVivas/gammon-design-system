# Marquee

Faixa de texto gigante (`marquee` 96px, 600) que corre da direita para a esquerda antes do rodapé, com as bordas esmaecidas por máscara. As frases alternam `green-brand` cheio e a 35%, como o efeito de preenchimento do site.

Repita o conteúdo duas vezes no trilho (a animação vai até -50%). Um marquee por página, sempre com o slogan da campanha. Parado em `prefers-reduced-motion`.
